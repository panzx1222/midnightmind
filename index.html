quickstart
from openai import OpenAI

client = OpenAI(
    api_key="sk-mm-xxxxxxxx",
    base_url="https://midnightmind.net/v1",
)

resp = client.chat.completions.create(
    model="kimi-k2",  # 或 deepseek-chat / glm-4
    messages=[{"role": "user", "content": "写一首关于午夜的诗"}],
    stream=True,
)
for chunk in resp:
    print(chunk.choices[0].delta.content or "", end="")
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: "sk-mm-xxxxxxxx",
  baseURL: "https://midnightmind.net/v1",
});

const resp = await client.chat.completions.create({
  model: "glm-4",  // 或 deepseek-reasoner / qwen3
  messages: [{ role: "user", content: "你好，MidnightMind" }],
});
console.log(resp.choices[0].message.content);

// FAQ

常见问题

MidnightMind API 和直接调用官方接口有什么区别？

你只需管理一个 Key、一份账单，就能调用多家厂商的模型；同时我们为每个模型配置多个上游渠道，单一渠道异常时会自动切换，稳定性更高。

现有项目迁移需要改多少代码？

我们完全兼容 OpenAI 协议。通常只需修改 base_url 与 api_key 两处配置，再把 model 改为想用的模型名即可。

支持流式输出和函数调用吗？

支持。SSE 流式输出、Function Calling / Tools、JSON Mode 等能力会随上游模型的支持情况同步开放。

你们会保存我的对话数据吗？

不会。我们仅记录计费所需的 Token 用量与调用元信息，不存储请求与回复内容。

如何充值与开具发票？

控制台支持在线充值，余额永不过期。企业用户可联系商务进行对公转账并开具发票。
